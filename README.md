# LaaBol play host

Public HTTPS build of the LaaBol kids game.

Play: **https://agentlab-dev.github.io/laabol-web/**

GitHub Pages is served from branch `main`, folder `/` (root). No Actions deploy is required.

If that URL 404s, a repo owner must enable Pages at
https://github.com/AgentLab-dev/laabol-web/settings/pages
— Source = Deploy from a branch, Branch = `main`, folder = `/` (root).

Source: https://github.com/AgentLab-dev/LaaBol
